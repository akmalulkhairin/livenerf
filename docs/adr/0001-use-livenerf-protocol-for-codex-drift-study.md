through Codex, with Sol tracked alongside it. Calibrate a new panel and collect
a fresh baseline so the existing compute monitor cannot influence the study's
selection or results.

results public. Report the calibrated panel's sensitivity before starting
the drift baseline.

Measure the named model as served through Codex. Reject observable reroutes,
retries and refusals. Disclose routing and moderation that the interface
does not expose.

models shift in the same direction under the decision rule, report a shared
shift and leave its cause open. If Sol fails validation, settle the control
choice before collecting the baseline.

including calibration. Keep the account-wide stop at 50% in any reported usage
window. Count usage we cannot attribute towards the study cap and leave headroom
for delayed meter updates. Report the change the design is powered to detect
at that budget.
